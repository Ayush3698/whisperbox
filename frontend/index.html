WhisperBox

Anonymous, tamper-evident submissions on Cardano (Preprod)

Submit a message

This demo page calls the same off-chain logic as offchain/src/submit.ts through a connected wallet (Nami / Eternl / Lace on Preprod). No wallet address is stored in the submission datum.

Why this is private by design

The validator only checks a one-time secret against a commitment hash — it never checks who is spending. That means redemption never needs to reference the sender's wallet, so there is no on-chain link between a submitter's identity and their message. See contracts/whisperbox.ak for the full validator.
